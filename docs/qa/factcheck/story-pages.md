# Fact-check — story-pages
Checked: ~235 statements on the frozen build (`/`, `/comprendre/`, `/comprendre/etat-partout/`, `/comprendre/agences/`, `/comprendre/le-plan/`, plus the global header/footer and the `<title>` / description / OG / Twitter metas of those five pages). I extracted the visible text, aria-labels, chart summaries (« Lecture : … »), the data tables folded in the `<details>`, and the source chips. For client-rendered islands I used Playwright: PredictReveal after « Révéler », Sankey in both horizons, Lifecycle in both modes, and the 856-line agency list. Each number was checked against `site/src/data/*.json`, `data/derived/csv/**` (cell by cell), the manifesto, the fiches, the lettres and the liasses (`research/pages/amendements__*.md`). The real-world claims were checked against Insee, DGAFP, France Travail and Unédic by web search.
Errors: 9 (blocker 0 / major 4 / minor 5). À vérifier: 8.
