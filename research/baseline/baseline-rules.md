# Baseline — French household tax-benefit model (current legislation)

**Legislation covered: 2026 rules, state of the law on 24 October 2026** (latest available).
Nothing here is 2025 law, except where a 2026 parameter is explicitly frozen/not revalorised (flagged).

| Block | Rule version used | Effective date |
|---|---|---|

| Plafond SS | PMSS 4 005 EUR/month (48 060/yr) — arrêté du 22/12/2025 | 1 Jan 2026 |

> **Important caveat on the income tax year.** In October 2026 no barème for *revenus 2026* exists yet (PLF 2027 is not enacted).
> "Current IR" therefore = the LF 2026 barème applied to the household's annual income, as if income were identical in 2025.
> All figures are *steady-state*: the household's income is assumed constant (so 3-month, 12-month and N-2 look-back rules see today's income).

## 1. Conventions and household input contract

* Amounts in EUR. "Monthly" = per month, "annual" = per year. Rates are fractions. All formulas use gross → net in that order.
* **Rounding.** Do not round intermediates, except where stated: RGDU coefficient second term (4 decimals), APL (§7.2), PA bonification max
  (cents), final monetary outputs (cents). IR is rounded to the euro in the official calculation (optional).
* **Steady state.** Monthly outputs correspond to a month of Oct 2026 for a household whose income has been constant.

```ts
interface Adult {
  age: number;
  status: 'salarie' | 'retraite' | 'inactif' | 'aah' | 'micro';        // micro = optional (§5)
  grossMonthly?: number;          // salaried: brut mensuel (CDI, full year)
  workRatio?: number;             // 0..1 (hours / 151.67); prorates the SMIC used by the RGDU (default 1)
  pensionGrossMonthly?: number;   // retired: base + complementary, gross
}
interface Household {
  couple: boolean;                // married/pacsed = joint IR; cohabiting unmarried partners are NOT modelled
  adults: Adult[];                // 1 or 2
  childrenAges: number[];         // all fiscal dependents and 'à charge' for benefits (age < 21 for APL/CF, < 20 for AF)
  housing: { status: 'locataire' | 'proprietaire' | 'gratuit'; rentMonthly?: number /* hors charges */; zone?: 1 | 2 | 3 };
  loneParentMajoration?: boolean; // RSA/PA "majoré" for recent separation (auto true if youngest child < 3)
  childSupportReceivedMonthly?: number; // default 0 => ASF is paid to a lone parent
  childcareExpensesPerChildUnder6?: number; // annual, crèche/assistante hors domicile (tax credit)
  company: { sizeGe50: boolean; atMpRate?: number /* default 0.0208 */; versementMobilite?: number /* default 0 */ };
}
```

**Calculation order (no circular dependency):**
1. salary chain per salaried adult (§3) and pension chain per retiree (§4) → `netPay`, `netTaxable`, employer cost
2. income tax (§6) → `rni`, `rfr`, `irNet` (pension CSG tier uses the RFR: fixed-point iterate 3–4 times)
3. `Rnc` = *revenu net catégoriel* (§7.1)
4. family benefits that depend only on `Rnc` : AF, PAJE base, CF, ARS, ASF (§7.3–7.7)
5. APL (§7.2) — depends on `Rnc`, rent, zone
6. RSA, PA (§7.8, §7.9) — depend on net earnings, AF/PAJE/CF/ASF (resources) and APL (housing flat rate)
7. ASPA / AAH (§7.10–7.11), disposable income (§8), VAT (§9)

## 2. What is modelled / not modelled

**Modelled:** private-sector salaried (non-cadre; cadre differs only by APEC 0.024 %/0.036 % — optional), retirees, IR (quotient familial, plafonnement,
décote, abattements 10 %, age ≥ 65 abattement, childcare credit), RGDU and full employer cost, PA, RSA (+ forfait logement), APL/AL (private rented
sector), AF (+ modulation, majoration d'âge, complément dégressif), CF, PAJE base (children < 3), ARS, ASF, ASPA, AAH (single), VAT estimate;
micro-entrepreneur (optional, **not oracle-checked**).

**Not modelled (flagged):** capital income and its CSG (10.6 % on produits de placement since 1 Jan 2026, per OpenFisca); mutuelle/prévoyance (employee and employer shares — real super-brut and
net are lower/higher); versement mobilité (parameter available, default 0); Alsace-Moselle; DOM; public servants; unemployment benefits; students/bourses; PCH; CMG/PreParE/prime à la naissance;
cohabiting (non-married) couples; HLM/conventionné specifics and RLS; colocation, chambres, foyers; accession (owner) aid; chèque énergie; CMU-C/C2S; taxe d'habitation (abolished for main homes);
CEHR/CDHR (parameters listed, formulas not validated); temporary 2026 fuel measures (indemnité carburant / aide « grands rouleurs » 100 EUR, décret 2026-959);
excise taxes (TICPE, tabac, alcool); exact monthly timing of declarations (trimestrial RSA/PA lag, APL 12-month window, AF/CF N-2) — replaced by steady state.

## 3. Salary chain (private sector, non-cadre) — brut → net and coût employeur

### 3.1 Employee side
Let `B` = monthly gross, `P` = `general.pmss_monthly` (4 005).
`T1 = min(B, P)`, `T2 = max(0, min(B, 8P) − P)`.

```
vieillesse_plaf   = 6.90 %  × T1                       salary.employee.vieillesse_plafonnee
vieillesse_deplaf = 0.40 %  × B                        salary.employee.vieillesse_deplafonnee
agirc_arrco       = 3.15 %  × T1 + 8.64 % × T2         salary.employee.agirc_arrco_t1/_t2
ceg               = 0.86 %  × T1 + 1.08 % × T2         salary.employee.ceg_t1/_t2
cet               = (B > P) ? 0.14 % × min(B, 8P) : 0  salary.employee.cet
(cadre: + apec 0.024 % × min(B, 4P))
cotisationsSalariales = sum of the above           (no employee maladie or chômage contribution since 2018)

csgBase   = 0.9825 × min(B, 4P) + max(0, B − 4P)       (4P = 16 020/month = 192 240/yr)
csgDed    = 6.8 % × csgBase ;  csgNonDed = 2.4 % × csgBase ;  crds = 0.5 % × csgBase
netPay        = B − cotisationsSalariales − csgDed − csgNonDed − crds      // "net à payer avant impôt" ≈ "net social"
netTaxable    = B − cotisationsSalariales − csgDed                          // "net imposable" (before 10 % abattement)
```
Check: SMIC 1 867.02 → cotisations 211.16, CSG ded. 124.74, CSG non-ded. 44.02, CRDS 9.17, **net 1 477.93 (official figure of service-public F2300: exact)**,
net taxable 1 531.12. Sources: URSSAF 2026 rates (republished: bpifrance-creation.fr/boiteaoutils/cotisations-sociales-du-regime-general-salaries),
service-public F2971 (CSG), Agirc-Arrco rates (FNTP, MSA, CAPEB, OpenFisca).

*Simplification:* the base `B` is fixed gross salary; employer-paid mutuelle/prévoyance, benefits in kind, heures sup exonérées, primes, 13th month etc. are not modelled.

### 3.2 Employer side ("coût employeur" / "super-brut")
Employer contributions **before** RGDU (rates 2026; `salary.employer.*`):

| Line | Base | Rate |
|---|---|---|
| Maladie-maternité-invalidité-décès | B | 13.00 % (the 7 % reduced rate is neutralised by the RGDU) |
| Vieillesse plafonnée | T1 | 8.55 % |
| Vieillesse déplafonnée | B | **2.11 %** (was 2.02 %) |
| Allocations familiales | B | 5.25 % (3.45 % reduced rate neutralised by the RGDU) |
| AT/MP | B | user input, default **2.08 %** (national mean net rate 2026) |
| FNAL | T1 if < 50 employees (0.10 %); B if ≥ 50 (0.50 %) | |
| CSA | B | 0.30 % |
| Assurance chômage | min(B, 4P) | **4.00 %** (4.05 % until 30 Apr 2025) |
| AGS | min(B, 4P) | **0.25 %** (OpenFisca still has 0.20 %) |
| Agirc-Arrco | T1 / T2 | 4.72 % / 12.95 % |
| CEG | T1 / T2 | 1.29 % / 1.62 % |

`employerGross = Σ lines`; `superBrut = B + employerGross − rgdu`.

### 3.3 Réduction générale dégressive unique (RGDU) — "Fillon" replacement since 1 Jan 2026
Law: CSS art. L241-13 (as amended by LFSS 2025 art. 18), décrets 2025-887 (4/9/2025), 2025-1446 (31/12/2025), **2026-509 (12/6/2026: SMIC reference frozen)**.

```
smicRef  = workRatio × 12.02 × 151.6667                      // FROZEN 1 Jan 2026 SMIC (not 12.31)
if (B ≥ 3 × smicRef)  coef = 0                               // cliff: at 3 SMIC the reduction falls from t_min (2 %) to 0
else {
  x    = max(0, 0.5 × (3 × smicRef / B − 1))
  coef = t_min + round(tDelta × x^1.75, 4)                   // t_min = 0.02 ; power 1.75
  coef = min(coef, t_min + tDelta)                           // tDelta = 0.3781 (< 50 employees, FNAL 0.10 %) or 0.3821 (≥ 50)
}
rgdu = coef × B                                              // = Tmax 0.3981 / 0.4021 at the SMIC
```
Examples (golden): SMIC 1 867.02 (reference 1 823.03 so ratio 2.9293): coef 0.3750 → **rgdu 700.13**; employer gross 800.87 → employer net of RGDU 100.74 (5.4 % of gross);
2 × SMIC (3 734.04): rgdu 184.46; at or above 3 × the frozen SMIC = **5 469.10 EUR gross** (2.93 × the current SMIC): 0 (the 2 % `t_min` disappears: employer cost jumps by ~109 EUR/month at the threshold).
`tDelta` = sum of the contributions in the scope (maladie 7 + vieillesse 8.55 + 2.11 + AF 3.45 + AT/MP 0.49 + CSA 0.30 + Agirc-Arrco 4.72 + 1.29 + chômage 4.00 + FNAL 0.10/0.50) **+ 5.80 pts**
compensating the removal of the maladie/famille bandeaux = 37.81 % / 38.21 % (sum documented in OpenFisca `t_delta_*` parameters; BOSS/FNTP give the same values).
*Simplifications:* annual remuneration = 12 × B (constant pay); `a`/`b` coefficients (overseas, apprentices, etc.) ignored; the reduction is not capped at the contributions actually due.
*Discrepancy:* a pre-decree Eurex note gave tDelta 0.3773; décret 2025-1446 / FNTP / OpenFisca say 0.3781 — we use 0.3781.

### 3.4 "Coin fiscal" decomposition to display (per salaried adult, monthly)
```
superBrut                       = B + employerGross − rgdu
  employer social contributions = employerGross − rgdu       (net of RGDU)
  employee contributions        = cotisationsSalariales
  CSG + CRDS                    = csgDed + csgNonDed + crds
netPay                          = superBrut − (all of the above)
+ income tax (§6, ÷12)  − benefits received (§7)  → disposable income  ;  − VAT (§9) → purchasing power
```

## 4. Retired persons — pension gross → net

Pensions = base + complementary, gross monthly `Pm`. (Not modelled: the 1 % maladie contribution withheld by Agirc-Arrco on complementary pensions for non-exempt retirees, whose applicability depends on fiscal situation.)

**CSG tier** depends on the household's RFR of year N−2 (RFR 2024 for 2026) and its number of parts `n` (steady state: use current `rfr` from §6):
```
k = (n − 1) × 2
exemptLimit  = 13 048 + k × 3 484
reducedLimit = 17 057 + k × 4 555
medianLimit  = 26 472 + k × 7 066          // pensions.csg_rfr_thresholds_1_part / csg_rfr_increment_half_part
tier = rfr ≤ exemptLimit ? 'zero' : rfr ≤ reducedLimit ? 'reduced' : rfr ≤ medianLimit ? 'median' : 'full'
```
(check: 2 parts → 20 016 / 26 167 / 40 604 as in service-public F2971.)

| Tier | CSG | of which deductible | CRDS | CASA | Total |
|---|---|---|---|---|---|
| zero | 0 | 0 | 0 | 0 | 0 |
| reduced | 3.8 % | 3.8 % | 0.5 % | 0 | 4.3 % |
| median | 6.6 % | 4.2 % | 0.5 % | 0.3 % | 7.4 % |
| full | 8.3 % | 5.9 % | 0.5 % | 0.3 % | 9.1 % |

```
pensionNet      = Pm × (1 − csgTotal − crds − casa)
pensionTaxable  = Pm × (1 − csgDeductibleRate)                    // annual: × 12, before the IR abattement
```
IR for pensions: abattement 10 % (min **454 EUR per pension holder**, max **4 439 EUR per foyer**), then the age-65 abattement (§6.1).
Golden: 1 200 EUR (RFR 10 138 → zero), 1 800 (median: 7.4 %), 4 000 (full: 9.1 %), couple 2 000 + 1 200 (median) — all match the oracle.
*Simplification:* tier switch rule "two consecutive years" and the lissage are ignored (steady state).
*Oracle quirk:* OpenFisca's `retraite_nette` may omit the deductible CSG depending on evaluation order (circular N-2 RFR dependency); the golden file rebuilds the net pension from its components.

## 6. Impôt sur le revenu (barème 2026 on revenus 2025)

### 6.1 Taxable income
```
for each salaried adult:   salNet_i = S_i − min(max(10 % × S_i, 509), 14 555)   [abattement ≤ S_i],   S_i = 12 × netTaxable_i
pensions (household):      pensNet  = Σ pTax_i − min(max(10 % × Σ pTax_i, 454 × #pension holders), 4 439)     pTax_i = 12 × pensionTaxable_i
rng = Σ salNet_i + pensNet
age-65 abattement (CGI 157 bis): if the declarant or the spouse is ≥ 65:  rng ≤ 17 670 → 2 822 ; rng ≤ 28 430 → 1 411 ; else 0   (applied once per foyer — OpenFisca)
rni = max(0, rng − ageAbattement)          // revenu net imposable ; rfr ≈ rni (no other items)
```
(Réel frais, déductions PER, pensions alimentaires etc. are not modelled.)

### 6.2 Quotient familial and barème
Parts `N`: declarant 1 (+1 if couple); child 1 and 2: +0.5 each; child 3+: +1 each; **parent isolé** (single, ≥ 1 child): +0.5.
```
bareme(q) = 0 %·[0, 11 600] + 11 %·]11 600, 29 579] + 30 %·]29 579, 84 577] + 41 %·]84 577, 181 917] + 45 %·]181 917, ∞[
nBase = couple ? 2 : 1
ir1 = N × bareme(rni / N)          ir0 = nBase × bareme(rni / nBase)
extraHalves = (N − nBase) / 0.5
cap = parentIsole ? 4 262 + 1 807 × max(0, extraHalves − 2) : 1 807 × extraHalves       // plafonnement de l'avantage QF
ir  = (extraHalves > 0) ? max(ir1, ir0 − cap) : ir1
```
(Check with the official worked examples of service-public F1419: couple + 1 child, RNI 90 000 → 11 400.98; parent isolé + 2 children, RNI 30 000 → 110.00 — reproduced by the oracle within 0.2 EUR.)

### 6.3 Décote, credits, collection
```
decote = max(0, (couple ? 1 483 : 897) − 45.25 % × ir)         // only effective when ir < 1 982 (single) / 3 277 (couple)
irAfterDecote = max(0, ir − decote)
creditGarde   = 50 % × min(expensesPerChild, 3 500) × (# children < 6)      // crèche/assistante agréée hors domicile; 1 750 max per child
irNet = irAfterDecote − creditGarde       // may be negative = refund of the credit
if (irAfterDecote < 61 and no credit) irNet = 0                  // seuil de recouvrement (CGI 1657)
```
Golden: SMIC single → IR before décote 543.01, décote 651 → **0**; 2 SMIC single → 3 026; couple + 2 children 2 × SMIC → 0; single 5k-net → 10 174; 10k-net → 30 667; 3 500 EUR childcare credit case → IR 1 332 after a 1 750 credit.
Sources: service-public F1419, F8 (credit, verified 15/04/2026), BOFiP actualité du 7/4/2026 (via legifiscal.fr), weblex.fr (abattement 509/14 555), CGI.
Not modelled: CEHR (3 %/4 % above 250k/500k single, 500k/1M couple — parameters in file), CDHR (20 % minimum rate above 250k/500k), PER, réductions (dons, emploi à domicile, scolarité), demi-parts spéciales (ancien combattant, invalidité), garde alternée, rattachement d'enfants majeurs.

## 7. Social benefits

### 7.1 Common definitions
* **Net earnings** for RSA/PA = `netPay` of each adult (net after CSG/CRDS, before tax; = « montant net social » since July 2023).
* **Revenu net catégoriel `Rnc`** (annual, N-2 proxy) = Σ salNet_i + pensNet (§6.1 before the 65+ abattement). Used for AF, PAJE, CF, ARS (and APL after rounding).
* **Household persons** `np = #adults + #children`; **couple factor** `f(np)`: 1 (np=1), 1.5 (2), 1.8 (3), 2.1 (4), 2.1 + 0.4 × (np − 4) (np ≥ 5). Used identically by RSA and PA.
* **Lone-parent majoration** (RSA/PA "majoré"): applies if single with a child and (youngest child < 3 **or** `loneParentMajoration` flag): `forfait = base × (1.28412 + 0.42804 × nChildren)`, taken if larger than `base × f(np)`.
* **Resources counted in RSA and PA** besides earnings: AF (`min(af_base, af)` i.e. before age majoration), CF at the *non-majoré* rate if CF is paid, PAJE base, ASF flat (22.5 % BMAF per child if ASF paid), ASPA, net pensions. APL/AL are replaced by the *forfait logement*. PA is not a resource of RSA and vice-versa.
* All family benefits, PA and housing aid are **paid net of 0.5 % CRDS** (RSA, AAH, ASPA are not). service-public shows the net figures (e.g. AF 152.25 = 153.01 × 0.995); the ministry shows gross. The model computes gross and applies CRDS at the end.

### 7.2 APL / AL — private rented sector, simplified (validated on the 16 golden cases with a positive housing aid, to the cent)
Inputs: zone `z ∈ {1,2,3}`, `couple`, `n` = number of children (dependents < 21), `rent` (monthly, hors charges), `R` = annual resources.
```
// resources (annual), then rounded UP to the next 100 EUR :
R = ceil100( Σ_salaried max(0, 12·netTaxable_i − abattement10%_i)  +  pensions after abattement )      // = Rnc
// ceilings (arrêté du 28/09/2026), parameters benefits.housing_apl_private_rented.rent_ceiling_zone{1,2,3}_*
L2(z) = n = 0 ? (couple ? ceil_z.couple : ceil_z.single) : ceil_z.one_child + max(0, n − 1) × ceil_z.per_extra_child
L = min(rent, L2(z))                           C = 61.29 + 13.90 × n          // forfait de charges
R0, TF from the (frozen) tables by composition: single / couple / n = 1..6 / +per extra
Lref = same composition but ALWAYS zone-2 ceilings
RLpct = round(100 × L / Lref, 2)
TLpct = RLpct ≥ 75 ? 0.0068 × (RLpct − 75) + 0.0045 × 30 : max(0, 0.0045 × (RLpct − 45))
TL = round(TLpct / 100, 5)                    Tp = TF + TL
P0 = max(8.5 % × (L + C), 40.01)             Pp = P0 + Tp × max(0, R − R0)
AL = max(0, L + C − Pp)
// dégressivité on rent (zone 1: 3.4 → 4.0 × L2 ; zones 2-3: 2.5 → 3.1 × L2):
coef = rent ≤ round(L2·d) ? 1 : rent > round(L2·s) ? 0 : 1 − (rent − round(L2·d)) / (round(L2·s) − round(L2·d))
AL = max(0, round(AL × coef, 2) − 5)           // minoration forfaitaire 5 EUR
if (AL < 10) AL = 0                           // minimum de versement (non-conventionné)
net of CRDS = AL × 0.995
```
Golden: SMIC single zone 2 → 0 (resources 16 600 ≫ R0); retiree 1 200 EUR (R = 13 000) rent 500 zone 2 → 66.53; no income single → 309.96; lone parent 2 children 1 SMIC rent 700 → 300.41.
*Simplifications:* no abattement for double activity (OpenFisca: 95 EUR/yr, ≤ 3 EUR/yr effect); no neutralisation rules (unemployment, retirement, RSA…); no student floor; N-2 vs 12-month window ignored; HLM/conventionné tenants use the same barème (APL minimum paid 0 instead of 10); no chambres/colocation; DOM excluded.
*Note:* the Oct-2026 revalorisation changes plafonds/charges/P0 only; R0 and TF were deliberately not revalorised for 2026 (arrêté du 28/12/2025).

### 7.3 Allocations familiales (AF)
Eligible children `n_af` = children < 20 (need ≥ 2). `Rnc` = revenu net catégoriel N-2 (steady state: current).
```
full = BMAF × {n=2: 0.32 ; n=3: 0.73 ; n=4: 1.14 ; n>4: 1.14 + 0.41 (n − 4)}              // BMAF = 478.16  → 153.01 / 349.06 / 545.10
T1 = 66 652 + 6 664 × n ;   T2 = 93 276 + 6 664 × n         // 2 children: 79 980 / 106 604 (official)
tierFactor = Rnc ≤ T1 ? 1 : Rnc ≤ T2 ? 0.5 : 0.25
maj = 0.16 × BMAF × #eligible-for-majoration          // 76.51 EUR per child
   eligible = age ≥ 18, or (born before 1 Mar 2012 → age ≥ 14);   NOT the eldest when n = 2
   → in 2026 proxy: age ≥ 15 (child aged 14 is ambiguous: treated as born after 1 Mar 2012 → no majoration)
AF = (full + maj) × tierFactor
degressive complement: if Rnc slightly above a ceiling Tk:  AF = max(AF, (Tk + 12 × AF_before_tier − Rnc) / 12)   // service-public F13213
af_base (for RSA/PA resources) = full × tierFactor
```
Golden: 2 children 153.01; 3 children (one 16-year-old) 425.57 = 349.06 + 76.51; income 88 736 → 76.50 (÷2); 133 532 → 38.25 (÷4).
*Simplifications:* allocation forfaitaire (20-year-old) ignored; degressive complement implemented as above; case `edge_af_degressif` (Rnc ≈ 80 800, just above 79 980): reference 84.54 vs oracle 82.91 (OpenFisca's N-2 base is ~20 EUR higher; without the complement it would be 76.51); DOM rules ignored; 1-child families get nothing (except PAJE/ARS).

### 7.4 Complément familial (CF)
≥ 3 children, **all** aged 3 to < 21. `m = 1 + 0.25·2 + 0.30·(nChildren − 2)`; `bonus` = couple with 2 incomes (each ≥ 6 306 EUR N-2) or lone parent.
```
ceilBase  = 24 853 × m + (bonus ? 9 989 : 0)        // 3 children: 44 735 (1 income) / 54 724 (2 incomes or lone) ; 4 children 52 191 / 62 180
ceilMajore= 12 429 × m + (bonus ? 4 995 : 0)        // 22 372 / 27 367 (3 children) ...
CF = Rnc ≤ ceilMajore ? 0.6248 × BMAF (298.76) : Rnc ≤ ceilBase ? 0.4165 × BMAF (199.15) : 0     // + complément différentiel near the ceiling (not modelled)
```
Golden: 3 children, 1.5 + 1 SMIC → 199.15; lone parent 3 children 1.5 SMIC → 298.75 (majoré); family with a child of 2 → 0 (all must be ≥ 3); income 58 000 → 0.

### 7.5 PAJE — allocation de base (children < 3)
`nU3` = children < 3; `nChild` = children < 20. `m = 1 + 0.25·min(nChild, 2) + 0.30·max(nChild − 2, 0)`.
```
plein   = 24 853 × m + (couple with 2 incomes or lone parent ? 9 989 : 0)
partiel = 29 694 × m + (… ? 11 936 : 0)
PAJE = nU3 × (Rnc ≤ plein ? 0.4165 : Rnc ≤ partiel ? 0.20825 : 0) × BMAF        // 199.15 / 99.58 per child
```
Included because OpenFisca pays it and it is counted as a resource of RSA/PA. (Prime à la naissance, CMG and PreParE are not modelled.) Source: OpenFisca parameters (CSS L531-1 s.), no official page read.

### 7.6 Allocation de rentrée scolaire (ARS) — paid once, in August
For each child aged 6–18 (age reached in the year): 6–10 → 0.8972, 11–14 → 0.9467, 15–18 → 0.9795 × BMAF (**429.01 / 452.67 / 468.36 EUR gross**; service-public shows 426.87 / 450.41 / 466.02 net of CRDS).
Ceiling `22 274 × (1 + 0.30 × nChildren)` (1 child 28 956; 2: 35 638; 3: 42 320; official). If `Rnc` exceeds it by less than the ARS: allocation différentielle = `ceiling + ARS − Rnc` (paid if ≥ 15 EUR). Display as ARS/12 per month.
Golden: 2 children aged 6 and 10 → 858.02; single parent 1 SMIC with children 4 and 9 → 429.01.

### 7.7 Allocation de soutien familial (ASF)
Single parent receiving no child support (default; `childSupportReceivedMonthly` otherwise deducted): `ASF = 0.422 × BMAF × (#children < 20) − childSupport` (201.78 EUR per child; ≥ 15 EUR). This is what OpenFisca assumes for every isolated parent.
Counted in RSA/PA resources as 22.5 % BMAF (107.59) per child. *Hypothesis flag:* many lone parents do receive a pension alimentaire.

### 7.8 RSA (revenu de solidarité active)
Age ≥ 25 (or with a child), not retired/AAH. Monthly, 3-month average (steady state).
```
socle = base × f(np)                         base = 651.69      → 651.69 / 977.54 / 1 173.05 / 1 368.55 / +260.68   (official table)
if loneParentMajoration: socle = max(socle, base × (1.28412 + 0.42804 × nChildren))     // 836.85 (pregnant), 1 115.80 (1 child), 1 394.75 (2)
FL = housing flat rate: 
   owner/free housing : rate × base × g(np)         ;  tenant with housing aid : min(AL gross, rate × base × g(np))   ;  else 0
   rate = 12 % (np=1) | 16 % (np=2) | 16.5 % (np ≥ 3) ;  g = 1 | 1.5 | 1.8      → 78.20 / 156.41 / 193.55 (official)
resources = Σ netPay + AF_base + PAJE + CF_nonmajoré(if CF>0) + ASF_flat + net pensions + ASPA
RSA = max(0, socle − FL − resources) ;  if RSA < 6 → 0         // not subject to CRDS
```
Golden: no income single zone 2 rent 450 → RSA 573.49 (= 651.69 − 78.20) + APL 309.96; lone parent 1 child isolement récent → 851.81 (= 1 115.80 − ASF 107.59 − FL 156.41); lone parent 2 children (non majoré) → 611.31.
*Simplifications:* no capital/patrimoine, no *neutralisation* of interrupted income, no intéressement, no RSA jeune, no experimental départements, no conditions d'activité (15 h).

### 7.9 Prime d'activité (PA)
```
forfait  = base × f(np)           base = 638.28 (Apr 2026)      // couple 957.42 ; couple + 1 child 1 148.90 ; +255.31 per extra (official)
if loneParentMajoration: forfait = max(forfait, base × (1.28412 + 0.42804 × nChildren))
bonif_i  = round(0.377 × 638.28, 2) = 240.63  ×  clamp((E_i − 59·h) / (138·h − 59·h), 0, 1)       h = hourly SMIC = 12.31  → 726.29 .. 1 698.78 EUR/month ; E_i = netPay_i
FL       = same as RSA but with the PA base:  rate × 638.28 × g(np), min(APL gross, ·) if housing aid, full flat if owner/free
E = Σ netPay_i        resources = E + AF_base + PAJE + CF_nonmajoré + ASF_flat + net pensions + ASPA
PA = max(0, forfait + Σ bonif_i + 0.5985 × E − max(resources + FL, forfait))        // eligibility: 18+, household earnings > 0
PA = PA ≥ 15 ? PA : 0          net of CRDS = PA × 0.995
```
Notes. (i) The `max(resources + FL, forfait)` term makes PA = 0.5985 × E + bonifications when the household's total resources are below the forfait (so PA stacks with RSA). (ii) 2026 is a transition year: rate 61 % → **59.85 %** and bonification max 29.101 % → **37.7 %** (full at 138 SMIC-hours instead of 120), applied from April 2026 but visible in payments from July–September 2026 because of the trimestrial reference. (iii) Official CAF simulator, January 2026, single, no housing: net 700/1 000/1 600/1 800/1 900/2 000 → 350/306/174/94/54/0 — OpenFisca gives 350.4/306.2/174.2/94.3/54.4/0 (net of CRDS).
Golden (Oct 2026): SMIC single, renter without aid → PA 230.88 gross (229.72 net); SMIC single owner → 154.28; lone parent 1 child (age 5) 1 SMIC → 289.24 (ASF 107.59 and AF counted as resources).

### 7.10 ASPA (optional)
Age ≥ 65 (62 if unfit). `R` = monthly resources (net pensions…). Single: `max(0, 1 043.59 − R)`. Couple, one member entitled: `min(1 043.59, max(0, 1 620.18 − R_couple))` (service-public: full amount if couple resources ≤ 576.59). Couple, both entitled: total `max(0, 1 620.18 − R_couple)`. Golden: pension 900 → 143.60. Couple cases and earnings abattements are not validated.

### 7.11 AAH (optional, single, own resources only since Oct 2023)
`AAH = max(0, 1 041.59 − R)`, `R` = personal monthly resources after earnings abattement 80 % on the part ≤ 30 % of annual gross SMIC and 40 % above; annual ceiling 12 499 EUR (+ 50 % per child). Golden: AAH only → 1 041.59 (+ APL 309.96). Earnings case, couples (conjugalisation) and ESAT are not validated.

## 8. Disposable income (revenu disponible) — definition used and shown

```
disposableMonthly = Σ netPay + Σ netPension + [micro: netBeforeTax]
                  + (PA×0.995 + RSA + AL×0.995 + AF×0.995 + CF×0.995 + ASF×0.995 + PAJE×0.995 + ASPA + AAH)
                  + ARS×0.995 / 12
                  − irNet / 12                         // irNet < 0 means a credit refund
```
Matches OpenFisca's `revenu_disponible` definition (net work income + pensions + benefits − direct taxes) except that VAT is not subtracted and ARS is smoothed over 12 months. Taxe d'habitation no longer exists for main homes.
Examples (Oct 2026, steady state): single SMIC zone 2 → 1 707.65; couple + 2 children 2 × SMIC → 3 549.95; lone parent 2 children 1 SMIC → 2 549.03; single 2 × SMIC → 2 703.69; retiree 1 800 EUR gross → 1 666.80 (+ IR 0).
(`golden-cases.json` stores the components so the TS tests can check each line.)

## 9. VAT paid — simple estimate by decile (indicative)

**Method.** `VAT = tauxEffort(decile) × disposableIncome` (annual), where the decile is that of the household's *niveau de vie* `NV = disposableAnnual / UC`
(UC: 1 + 0.5 per other person ≥ 14 + 0.3 per child < 14; INSEE definition).
VAT/disposable-income ("taux d'effort") — Conseil des prélèvements obligatoires (note n° 6, Sept. 2023, citing Boutchenik/CPO 2015, Ines on Budget de famille 2011; rates structure unchanged since 2014):

| D1 | D2 | D3 | D4 | D5 | D6 | D7 | D8 | D9 | D10 |
|---|---|---|---|---|---|---|---|---|---|
| **12.5 %** | **9.5 %** | 9.21 %* | 8.93 %* | 8.64 %* | 8.36 %* | 8.07 %* | 7.79 %* | **7.5 %** | **4.7 %** |

\* **linear interpolation** between the published D2 (9.5 %) and D9 (7.5 %) (the CPO says the ratio "décroît de 9,5 % à 7,5 %" over D2–D9) — not a published series.
Decile cut-offs for NV (INSEE, niveau de vie 2023, per UC): D1 13 460, D5 25 760, D9 46 960 (published); D2–D4, D6–D8 are linear interpolations (16 535 / 19 610 / 22 685 / 31 060 / 36 360 / 41 660) — replace with INSEE ERFS/Filosofi deciles if you can.
Alternative published anchors: INSEE Économie et Statistique 522-523 (André & Biotteau 2021, Ines 2016): **13.1 % (D1) vs 7.4 % (D10)** of disposable income (different income definition) → ±1.5 pt uncertainty on levels.
Cross-checks usable in a footnote: VAT ≈ 10.7 % of household consumption (97.3 bn / 906.7 bn, Ines 2016); consumption = 97 % of disposable income for D1–D2 vs 72 % for D9–D10 (INSEE Première 2020 via CPO).
*Caveats:* these are 2011-structure estimates on *disposable income before VAT*; high savers (D10) are the least reliable; other indirect taxes (TICPE, tabac, alcool) are excluded — IPP (Dauvergne, 2012) finds total indirect taxes ≈ 14 % of permanent income in D1 vs 9 % in D10.
VAT rates for reforms that change them: normal 20 %, intermediate 10 %, reduced 5.5 %, particular 2.1 % (`vat.rate_*`); household spending split 2016: 52.2 % normal-rate / 13.3 % 10 % / 15.4 % 5.5 % / 0.6 % 2.1 % / 18.5 % exempt (INSEE ES 522-523, table 1).

## 12. Simplifications, discrepancies and open issues (explicit)

**Source access.** From the research sandbox, legifrance.gouv.fr, urssaf.fr, caf.fr (bot wall), boss.gouv.fr, info.gouv.fr and impots.gouv.fr (under maintenance) were not reachable. Values were therefore read on service-public.gouv.fr, solidarites.gouv.fr, BOFiP (via LégiFiscal), INSEE, ccomptes.fr, press/specialist republications of the URSSAF/BOSS tables, and the OpenFisca-France parameter files (which cite the Légifrance texts). Légifrance URLs in `parameters.json` come from those OpenFisca references and from search results; they were not opened. Each parameter carries a `status` (`official`, `official_republished`, `oracle`, `derived`).

**Source discrepancies resolved**
1. *AF/CF/ARS amounts*: service-public shows AF 152.25, CF 198.16/297.27, ARS 426.87/450.41/466.02 — these are **net of 0.5 % CRDS** (BMAF 475.78 = 478.16 × 0.995). The ministry (solidarites.gouv.fr) shows gross: AF 153.01, ARS 429.01/452.67/468.36. Model = gross then CRDS.
2. *AGS 0.25 %* (WebLex, Legisocial, URSSAF table) vs OpenFisca 0.20 % (stale) → golden script patches OpenFisca to 0.25 %.
3. *RGDU tDelta* 0.3781/0.3821 (décret 2025-1446; FNTP; OpenFisca) vs 0.3773 (early Eurex note).
4. *Micro-BNC rate* 25.6 % (OpenFisca 2026, décret 2025-943) vs 24.6 % (several blogs; the 2025 rate).
5. *Service-public PA page* quotes "26.29 EUR for 700 EUR" although the bonification starts at 726.29 EUR; we follow the decree/OpenFisca formula (confirmed by the CAF numbers).
6. *Press says PA bonification "+50 EUR on average"*: official figures are 184.27 → 240.63 EUR max (+56.36) with the full amount reached at 1.15 SMIC.

**Known artefacts when comparing with the oracle**
* `sp2_1_5smic`: PA differs by ~6 EUR because OpenFisca's PA for October uses the housing benefit of Jul–Sep (before the 1 Oct APL revalorisation) for the forfait logement. Vanishes when benefits are unchanged over 3 months.
* `edge_af_degressif`: reference 84.54 vs oracle 82.91 because the oracle's N-2 resource base is ~20 EUR higher (tolerance 7 EUR near ceilings).
* OpenFisca uses 151.67 h/month (legal 151.6667): the 4-decimal RGDU coefficient can flip by 1e-4 (≤ 0.4 EUR/month).
* IR/RNI: oracle rounds salary and tax to whole euros (≤ 3 EUR/yr; 6 EUR on the largest case).
* `retraite_nette` quirk (§4).
* Age-14 child and the AF majoration: depends on the exact birth date (before/after 1 March 2012); golden cases avoid age 14.

**Simplifications to keep in the UI footnotes**
* constant income (steady state); one barème (LF 2026) for IR; no mutuelle/prévoyance; no capital income; unmarried couples treated as singles; DOM/Alsace-Moselle excluded;
* APL: private tenants only, no double-activity abattement, no neutralisations; ASF/PAJE assumptions (§7.5, §7.7); RSA/PA no patrimoine, no experimentation, no active-search conditions;
* AAH/ASPA/micro are indicative (only partly oracle-validated);
* VAT: D3–D8 effort rates and NV cut-offs are interpolations; 2011 consumption structure.

**Things to re-check if the parent project needs "latest" values later:** PLF 2027 (IR barème, possible freeze), 1 Jan 2027 SMIC, 1 Apr 2027 revalorisations, RGDU parameters 2027 (the frozen-SMIC rule was for 2026), the LFSS 2027 (CSG, cotisations), the planned "allocation sociale unique".
